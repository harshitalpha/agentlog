# Reference material (read-only)

- `prototype/agentlog.py` + `prototype/ui.html`: a working Python prototype of the whole tool
  (run: `python3 prototype/agentlog.py init <dir>` then `python3 prototype/agentlog.py ui <dir>`).
  Use it to see the intended behaviour. The target implementation is Go (see docs/02-architecture.md).
  Known bugs in it are listed in docs/02-architecture.md §4. Don't copy them.
- `screenshots/`: what the prototype UI looks like. Note the too-wide line-number columns in the diff: that's bug #2.
